Introduction

This repository contains 15 HTML and CSS lab assignments completed as part of the BCS352 course. These assignments cover Git and GitHub basics, HTML elements, forms, tables, CSS styling, layouts and responsive web design.

The purpose of these assignments is to understand the fundamentals of web development through practical examples and improve basic HTML and CSS programming skills.


Assignment 1: Starting a Git Repository

Aim: To create a Git repository and save project work using commits.

Theory:

Git is a version control system used to track changes in files and manage project history. The "git init" command creates a new repository. The "git add" command stages files, while "git commit" saves changes in the repository. Git configuration commands are used to set the user's name and email.

Assignment 2: Pushing and Cloning a Repository

Aim: To understand how to push commits to a remote repository and clone an existing repository.

Theory:

Git allows developers to share and manage their code using remote repositories. The "git remote" command connects a local repository to a remote one. The "git push" command uploads commits, while "git clone" creates a local copy of an existing repository.

Assignment 3: Your First HTML Page

Aim: To create a basic HTML page using titles, headings, paragraphs and text formatting.

Theory:

HTML stands for HyperText Markup Language. It is used to create the structure of web pages. HTML provides elements such as "h1", "h2", "h3" and "p" for headings and paragraphs. The "strong" and "em" elements are used to highlight important text and emphasize words. The "br" element is used to insert a line break.

Assignment 4: Divs, Attributes and a Small Fix

Aim: To group webpage content using div elements, use attributes and correct HTML errors.

Theory:

The "div" element is a container used to group different parts of a webpage. Attributes provide additional information about HTML elements. The "id" and "class" attributes help identify and style elements, while custom data attributes such as "data-topic" store additional information. Correct HTML structure is important for displaying webpages properly.

Assignment 5: Links and Images

Aim: To connect different HTML pages using links and display images with alternative text.

Theory:

The anchor element "a" is used to create hyperlinks between webpages. The "href" attribute specifies the destination of a link. The "img" element is used to display images, while the "src" attribute specifies the image location. The "alt" attribute provides alternative text when an image cannot be displayed and improves accessibility.

Assignment 6: Types of HTML Lists

Aim: To create unordered, ordered, nested and description lists in HTML.

Theory:

HTML provides different types of lists to organize information. The "ul" element creates an unordered list, while "ol" creates an ordered list. The "li" element represents individual list items. Nested lists are used to create lists inside other lists, and description lists use "dl", "dt" and "dd" elements to display terms and their explanations.

Assignment 7: About Me Page

Aim: To create an About Me webpage using semantic HTML elements and contact links.

Theory:

Semantic HTML elements describe the meaning of webpage content. Elements such as "header", "nav", "main", "section" and "footer" help organize a webpage. The "id" attribute allows links to jump to specific sections, while the "mailto:" link is used to open an email application for contacting someone.

Assignment 8: Sign-Up Forms and Choices

Aim: To create labelled forms using text, email, password, radio buttons and dropdown fields.

Theory:

HTML forms are used to collect information from users. The "form" element contains input fields and other form controls. Different input types such as text, email and password are used for different kinds of information. Radio buttons allow users to select one option, while the "select" element creates a dropdown list. The "required" attribute makes a field compulsory.

Assignment 9: Tables with Headers and Footers

Aim: To create HTML tables using captions, headers, body sections, footer sections and scope attributes.

Theory:

HTML tables are used to display information in rows and columns. The "table" element creates a table, while "tr", "th" and "td" represent rows, headings and data cells. The "caption" element provides a table title. The "thead", "tbody" and "tfoot" elements organize table sections. The "scope" attribute improves accessibility by identifying the relationship between header cells and data cells.

Assignment 10: CSS Fundamentals

Aim: To apply inline, internal and external CSS and use selectors to style webpage elements.

Theory:

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML webpages. CSS can be applied using inline styles, internal style blocks or external stylesheets. Selectors such as element selectors, class selectors and ID selectors are used to target HTML elements. CSS properties control colours, fonts, backgrounds and text appearance.

Assignment 11: Units and CSS Variables

Aim: To understand CSS measurement units and use variables for colours, spacing and font sizes.

Theory:

CSS provides different units to control the size and spacing of webpage elements. Units such as "px", "%" and "rem" are commonly used in web design. CSS variables allow developers to store reusable values. They are commonly declared inside the ":root" selector and accessed using the "var()" function.

Assignment 12: Box Model, Cards and Scrolling

Aim: To understand the CSS box model, create styled cards and control overflowing content.

Theory:

The CSS box model describes how every HTML element is displayed as a box. It consists of content, padding, border and margin. The "box-sizing" property controls how the width and height of an element are calculated. CSS properties such as "border-radius" and "padding" help create attractive cards. The "overflow" property controls how extra content is displayed or scrolled.

Assignment 13: Flexbox Layouts

Aim: To create navigation bars, centred cards and wrapping layouts using CSS Flexbox.

Theory:

Flexbox is a CSS layout system used to arrange elements in rows or columns. It makes it easier to align and distribute items inside a container. The "display: flex" property enables Flexbox. Properties such as "justify-content", "align-items" and "flex-wrap" control alignment, spacing and wrapping of elements.

Assignment 14: CSS Grid Layouts

Aim: To create equal-column grids, responsive galleries and webpage layouts using CSS Grid.

Theory:

CSS Grid is a layout system used to arrange elements in rows and columns. It allows developers to create structured and responsive webpage layouts. The "display: grid" property enables Grid. Properties such as "grid-template-columns", "gap" and "grid-template-areas" help control the structure and arrangement of grid items.

Assignment 15: Responsive Pages with Media Queries

Aim: To create responsive webpages using media queries, flexible images and relative font sizes.

Theory:

Responsive web design allows webpages to adjust their layout according to different screen sizes. CSS media queries apply styles based on screen conditions such as width. The viewport meta tag helps webpages display correctly on mobile devices. Properties such as "max-width: 100%" and "height: auto" make images responsive, while "rem" units help create flexible text sizes.
